# Git Conflict Lab

This project was created to practice Git branches, merging, and resolving merge conflicts.

## What I Practiced

- Creating a Git repository
- Creating and switching branches
- Editing the same file on different branches
- Merging branches
- Identifying a merge conflict
- Resolving a merge conflict
- Committing the resolved file
- Pushing the project to GitHub

## Files

- `family.txt` – used to practice creating and resolving a merge conflict
- `.gitignore` – tells Git which files or folders should not be tracked

## Git Commands Used

```bash
git status
git branch
git switch -c branch-name
git add .
git commit -m "commit message"
git switch master
git merge branch-name
git push
